A vector embedding converts data — such as text, images, or audio — into a numerical representation (a high-dimensional vector, e.g., a 1,256-dimensional array) that captures its semantic meaning.

1. Understanding Vector and Semantic Relationships:

The image is a visual representation of a vector space model, likely used to illustrate semantic relationships between words. The central point represents a neutral or undefined state. From this point, vectors radiate outward to different terms representing demographic categories (Man, Woman, Boy, Girl, Old, Infant, Child). The positioning and direction of these vectors suggest relationships and potential axes of differentiation.

Here’s a breakdown based on vector embedding concepts:

Dimensions: The model appears to use at least two dimensions (though more dimensions could be conceptually inferred): Gender (Man/Woman, Boy/Girl) and Age (Old/Infant, Child). These are not orthogonal, as the age dimension can be interpreted as crossing the gender dimensions.
Vector Representation: Each word is represented by a vector originating from the center. The length or direction of the vector could represent the magnitude or direction of the semantic relationship to the central point (which is undefined).
Semantic Relationships: The arrows indicate relationships between the words. For instance, “Man” is opposite “Woman,” “Old” is opposite “Infant,” and so forth. The placement suggests antonyms or contrasting concepts.
Limitations: The model is simplified. Real-world word embeddings are far more complex and multidimensional, capturing nuances of meaning beyond simple binary oppositions. The model doesn’t show relationships between non-opposite terms (e.g., the relationship between “Man” and “Boy” isn’t explicitly shown). Additionally, “His” and “Her” represent possessive pronouns tied to gender, but are not precisely placed along the gender axis.
In summary, the image provides a basic, two-dimensional visualization of a vector space model. While illustrative, it’s a simplified representation of the complexities inherent in representing semantic relationships computationally. It effectively demonstrates the core concept of word vectors representing words as points in a space, with closer distances reflecting relationships.

Step4: Creates an instance of OpenAI’s embedding model It will be used to convert each text chunk into a vector.

Step5: Imports the embedding model wrapper for OpenAI. This is used to convert text into high-dimensional vectors (embeddings) using OpenAI’s model like text-embedding-ada-002.

Step6: Store vectors into Vector database like Chroma, FIASS, Pinecone, etc.

Step7: Submit a query, which will also get converted into a vector, and the system compares it to stored vectors using similarity metrics like cosine similarity or Euclidean distance.

The most similar vectors — called nearest neighbors — are returned as results, enabling a search based on meaning and intent rather than exact keyword matches.

We will be using a RetrievalQA chain to answer user queries by retrieving relevant chunks and generating answers via an OpenAI language model.

# FAISS vector store from LangChain for storing and searching document embeddings
from langchain.vectorstores import FAISS

# OpenAI embeddings to convert text into high-dimensional vectors
from langchain.embeddings.openai import OpenAIEmbeddings

# Import a simple text splitter that splits large text into manageable chunks
from langchain.text_splitter import CharacterTextSplitter

# Import a loader to read plain text document, we can 
# use PyPDFLoader for PDF and PandasExcelLoader for excel
from langchain.document_loaders import TextLoader

# Import the RetrievalQA chain to combine vector search with question-answering
from langchain.chains import RetrievalQA

# Import the OpenAI LLM wrapper to generate answers from retrieved documents
from langchain.llms import OpenAI

# Load environment variables from a .env file (e.g., API keys)
from dotenv import load_dotenv

# Built-in Python module to access environment variables
import os

# Load document having detail
loader = TextLoader("test.txt")  # or PDF/CSV loader
documents = loader.load()

# Create an instance of the CharacterTextSplitter with specified chunk size and overlap
# This splitter breaks large text into smaller chunks of 500 characters with a 50-character overlap
text_splitter = CharacterTextSplitter(chunk_size=500, chunk_overlap=50)

# Apply the text splitter to the loaded documents
# This returns a list of smaller, manageable text chunks that can be used for embedding
docs = text_splitter.split_documents(documents)

# Load Open API Key from .env environement variable
load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")

# Generate embeddings using Open API Key
embedding_model = OpenAIEmbeddings(openai_api_key=api_key)

# Create vector store
vectorstore = FAISS.from_documents(docs, embedding_model)

# Save locally using FIASS
vectorstore.save_local("faiss_index")

retrievalQueryChain = RetrievalQA.from_chain_type(
    llm=OpenAI(),  # Or ChatOpenAI() if using GPT-4-turbo
    retriever=vectorstore.as_retriever(k=3)
)

# Run a query through the RetrievalQA chain to get an answer based on the embedded documents
result = retrievalQueryChain.run("What is the name of programmar in one word?")
print(result)

result = retrievalQueryChain.run("How many years of experience imran having")
print(result)

Load Content From Earlier Created Vector Store in Place Of directly Text File
The code loads a saved FAISS vector store names as faiss_index, sets up a retrieval-based QA system using OpenAI embeddings and language models, and runs queries to get answers from the stored documents.

from langchain.vectorstores import FAISS
from langchain.embeddings.openai import OpenAIEmbeddings
from langchain.chains import RetrievalQA
from langchain.llms import OpenAI
from dotenv import load_dotenv
import os


load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")

# Create an embedding model instance using the OpenAI API key
embedding_model = OpenAIEmbeddings(openai_api_key=api_key)

# Load the FAISS vector store from the local directory using the same embedding model
# Note: `allow_dangerous_deserialization=True` should only be used if you trust the source
vectorstore = FAISS.load_local("faiss_index", embeddings=embedding_model, allow_dangerous_deserialization=True)

# Convert the vector store into a retriever that can be used for semantic search
retriever = vectorstore.as_retriever()


retrievalQueryChain = RetrievalQA.from_chain_type(
    llm=OpenAI(),
    retriever=retriever
)


result = retrievalQueryChain.run("What is the name of programmar in one word?")
print(result)

result = retrievalQueryChain.run("How many years of experience imran having")
print(result)
